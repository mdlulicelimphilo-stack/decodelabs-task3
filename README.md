## Description
A content-based recommendation system that matches user skills to job roles using TF-IDF vectorization and Cosine Similarity.

## Features
- User inputs 3 skills
- TF-IDF for feature weighting (penalizes common words)
- Cosine similarity for vector matching
- Top 3 job role recommendations
- Skill gap analysis
- Handles low-match scenarios
